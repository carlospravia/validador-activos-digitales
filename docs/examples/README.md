# Ejemplos oficiales

HTML de referencia para probar el **Validador de Activos Digitales** con el flujo incremental de la Clase 3.

## Disponible

| Ejemplo | Descripción |
|---------|-------------|
| [`activo-digital-blog/`](./activo-digital-blog/) | Artículo de blog sobre creación de activos digitales (`index-v1` → `index-final`) |

## Convención

Cada ejemplo debe incluir, como mínimo:

1. Los cinco archivos del ejercicio: `index-v1.html`, `index-v2.html`, `index-v3.html`, `index-v4.html`, `index-final.html`
2. Un `README.md` con tema, intención y cómo validar cada etapa
3. Contenido coherente con la hoja de trabajo (sin inventar evidencia)

Los ejemplos oficiales también se cargan en la app desde `src/data/sampleFiles.ts` (import `?raw` de estos archivos) para que la documentación y la UI no diverjan.
